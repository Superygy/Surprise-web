A LITTLE SURPRISE FOR YOU ♡
==========================

This is a romantic surprise website, not a birthday website. It is designed to
make your girlfriend feel loved and special, with a revealable love letter, a
playful Yes/No question, floating hearts, and optional background music.

HOW TO OPEN IT
1. Extract the surprise_website folder from the ZIP.
2. Keep index.html and the assets folder together.
3. Double-click index.html to open it in a modern browser.

HOW TO ADD YOUR OWN BACKGROUND MUSIC
1. Choose an MP3 music file you are allowed to use.
2. Copy it into the assets folder.
3. Rename that copy to exactly: our-song.mp3
4. Open (or refresh) index.html and click “Play our song”.

The music button is intentionally click-to-play because browsers generally
require a user gesture before audio can start. The rest of the website works
without a music file.

PERSONALIZATION
You can open index.html in a text editor to edit the love letter or wording.
The couple photo is stored at assets/couple-portrait.png.

FILES
- index.html                Main website
- assets/couple-portrait.png  Couple image used on the page
- assets/our-song.mp3         Add your own music file here (not included)

Have fun surprising your Cutuu. ♡
